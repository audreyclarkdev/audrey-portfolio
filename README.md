# Audrey Clark — Software Engineer Portfolio

🔗 [audreyclark.dev](https://audreyclark.dev)

![Portfolio Preview](public/portfolio-screenshot.png)

A single-page portfolio built with React and Vite, showcasing my journey from humanitarian work and QA engineering into full-stack software development.

## About

This site presents my work experience, projects, skills, education, and contact info in one place. It has a dark theme with gradient accents, smooth scroll navigation, and a layout that works on phones and desktops.

## How It Was Built

I built this site with AI-assisted development, using [Claude](https://claude.ai) as a coding partner. Most of the code was generated from my prompts; my role was to:

- **Set the direction** — decide what the site needed to say, which sections to include, and how it should look and feel
- **Write the content** — all experience, project descriptions, and copy are my own
- **Review and test** — check each change in the browser and ask for fixes when something looked or behaved wrong (my QA background came in handy here)
- **Iterate** — refine colors, layout, and details over many rounds of feedback
- **Ship it** — manage the Git repo and deploy to Vercel with a custom domain

As a recent graduate of Austin Community College's Full Stack Software Bootcamp and a member of the 100Devs and Dallas Software Developers Group tech communities, I make thorough and efficient use of AI tools as part of how I work.

## Tech Stack

- React
- Vite
- CSS (no UI library — all custom styles)
- Deployed on Vercel

## Features

- Sticky nav that highlights the current section
- Animated shimmer effect on the hero text
- Fully responsive layout
- Smooth scroll between sections
- Links to project repos on GitHub and to company websites

## Run It Locally

Requires [Node.js](https://nodejs.org/).

```bash
git clone https://github.com/audreyclarkdev/audrey-portfolio.git
cd audrey-portfolio
npm install
npm run dev
```

Then open the local URL shown in the terminal (usually http://localhost:5173).
